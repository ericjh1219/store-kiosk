# 门店互动屏（Android 闺蜜机 Web App）

顾客走近 → 摄像头检测到人脸 → 角色挥手语音欢迎 → 举手猜拳（手势识别）→ 赢了抽奖品 / 输了送安慰券 → 人离开后回到待机。

## 文件
- `config.js` —— 店名、台词、奖品、库存、触发距离、角色视频（**只需要改这个**）
- `app.js` —— 流程逻辑（MediaPipe 人脸检测 + 手势识别，全部在设备本地运行，不上传画面）
- `index.html` / `style.css` —— 画面

## 本机测试
```
python3 -m http.server 8765
```
用 Chrome 打开 http://localhost:8765 ，点「启动」，允许摄像头。连点店名 5 次可显示摄像头调试画面。

## 放到闺蜜机上
1. 摄像头必须在 **HTTPS** 下才能用。把整个文件夹拖到 Netlify Drop / Cloudflare Pages / Vercel，得到一个 https 网址。
2. 闺蜜机安装 **Fully Kiosk Browser**（推荐）：设为开机自启、全屏锁定、允许摄像头和自动播放声音、屏幕常亮。也可以用 Chrome「添加到主屏幕」。
3. 屏幕竖放，前置摄像头朝向门口人流。

## 换成真人感 AI 角色
在 `config.js` 的 `videos` 填上竖屏 mp4（待机/挥手/开心/失落 4 段），放进 `assets/` 文件夹。视频可以用数字人 / AI 视频工具生成，背景做成店铺风格。

## 中国大陆网络
Google 的模型地址可能打不开。把 `config.mediapipe` 里的 3 个地址对应文件下载到 `models/` 文件夹，改成本地路径即可（wasm 是整个文件夹）。

## 注意
- 奖品库存记录在这台设备的浏览器里，每天自动重置；多台设备或要防重复领取，需要加一个后端（核销码记录）。
- 摄像头只做本地检测、不存储画面；店门口建议贴「本设备使用摄像头互动」的告示。
